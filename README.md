# Ателье Анны v1.0.0

Уютная mobile-first PWA-игра про швею Анну: уход за героиней, заказы «три в ряд» и мини-игра с рисованием.

## Требования

- Node.js `>=22.13.0`
- npm (используется `package-lock.json`)

## Разработка и проверка

```bash
npm ci
npm run dev
npm run lint
npm test
```

## Production-сборка

Статическая сборка, пригодная для обычного веб-хостинга:

```bash
npm run build:release
```

Результат создаётся в `builds/atelier_anna_web_v1.0.0/`. Точка входа — `index.html`.

Пути к скриптам, стилям и игровым ресурсам относительные, поэтому папку можно размещать не только в корне домена, но и, например, в `/games/atelier-anna/`.

## PWA и установка

Манифест находится в `public/manifest.webmanifest`, service worker — в `public/service-worker.js`. Они используют относительный scope и работают из `/games/atelier-anna/` и других подкаталогов.

- Android/Chromium: игра перехватывает `beforeinstallprompt` и показывает собственную кнопку «Добавить на телефон».
- iPhone/iPad: кнопка показывает инструкцию Safari → «Поделиться» → «На экран Домой».
- В установленном режиме кнопка установки скрывается.
- Навигационный HTML и API авторизации не кэшируются service worker, поэтому установка не заменяет проверку покупки.

Иконки Home Screen находятся в `public/icons/`: Apple `180×180`, обычные PWA `192×192` и `512×512`, maskable `512×512`.

## Локальный запуск production-версии

Открывать `index.html` двойным щелчком не рекомендуется: браузеры ограничивают загрузку JavaScript-модулей через `file://`. Запустите любой статический HTTP-сервер из корня сборки, например:

```bash
npm run serve:release
```

После запуска откройте `http://127.0.0.1:4173/`. SPA rewrite не требуется: у игры одна статическая точка входа.

## Сохранения

Прогресс автоматически хранится в браузере в versioned-ключе `atelier_anna_save_v1`. Повреждённые и несовместимые сохранения безопасно игнорируются. Кнопка «Новая игра» полностью очищает прежний прогресс и создаёт новое начальное состояние.

## Публикация

GitHub Pages собирается workflow `.github/workflows/pages.yml` командой `npm run build:pages`. Для размещения на другом статическом хостинге загрузите всё содержимое папки release-сборки без изменения её внутренней структуры.

Для платной публикации на ULTRANEWERSTOP недостаточно открытого статического GitHub Pages: доступ к `/games/atelier-anna/` и игровым ресурсам должен проверяться сервером магазина по защищённой сессии и реальному entitlement. Клиент не содержит и не создаёт небезопасный флаг владения в `localStorage`.

Контракт авторизации, Web Push API, VAPID, проверка уведомлений и точные требования к серверу описаны в `docs/ULTRANEWERSTOP_DEPLOYMENT.md`.
