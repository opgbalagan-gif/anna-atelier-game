# Ателье Анны v1.0.0

Уютная браузерная игра про швею Анну: уход за героиней, заказы «три в ряд» и мини-игра с рисованием.

## Требования

- Node.js `>=22.13.0`
- npm (используется `package-lock.json`)

## Разработка и проверка

```bash
npm ci
npm run dev
npm run lint
npm test
```

## Production-сборка

Статическая сборка, пригодная для обычного веб-хостинга:

```bash
npm run build:release
```

Результат создаётся в `builds/atelier_anna_web_v1.0.0/`. Точка входа — `index.html`.

Пути к скриптам, стилям и игровым ресурсам относительные, поэтому папку можно размещать не только в корне домена, но и, например, в `/games/atelier-anna/`.

## Локальный запуск production-версии

Открывать `index.html` двойным щелчком не рекомендуется: браузеры ограничивают загрузку JavaScript-модулей через `file://`. Запустите любой статический HTTP-сервер из корня сборки, например:

```bash
npm run serve:release
```

После запуска откройте `http://127.0.0.1:4173/`. SPA rewrite не требуется: у игры одна статическая точка входа.

## Сохранения

Прогресс автоматически хранится в браузере в versioned-ключе `atelier_anna_save_v1`. Повреждённые и несовместимые сохранения безопасно игнорируются. Кнопка «Новая игра» полностью очищает прежний прогресс и создаёт новое начальное состояние.

## Публикация

GitHub Pages собирается workflow `.github/workflows/pages.yml` командой `npm run build:pages`. Для размещения на другом статическом хостинге загрузите всё содержимое папки release-сборки без изменения её внутренней структуры.
